# Better together

Проект "Better together" — представляет собой игру, в которой игрок может исследовать карту, сталкиваясь с интерактивными точками, каждая из которых открывает мини-игру. Игра посвящена космонавту Андрияну Николаевичу, родом из Чувашии, и рассказывает о этапах его жизни с мини-играми.

---

## Описание проекта

Данный проект предлагает игрокам возможность перемещения по карте, исследуя различные моменты из жизни Андрияна Николаевича. На карте расположены интерактивные точки, с которыми игрок может взаимодействовать. Каждая точка открывает новое окно с мини-игрой, рассказывающей о знаковых событиях, достижения космонавта и его вкладе в космонавтику.

---

## Функционал

- **Исследование карты**: Игрок может свободно перемещаться по карте, открывая для себя моменты жизни космонавта.

- **Интерактивные точки**: На карте есть метки, которые обозначают места взаимодействия, при этом каждая точка связана с определенной главой из жизни Андрияна Николаевича.

- **Мини-игры**: Каждая интерактивная точка запускает уникальную мини-игру.
